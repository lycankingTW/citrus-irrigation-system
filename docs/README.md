# 柑橘園智能灌溉計算系統

## 📋 系統概述

本系統是專為柑橘園設計的智能灌溉計算工具，依逐日作物係數、耗水限值與土壤水分收支，判斷當日要不要灌溉以及灌溉深度。

### 🎯 主要功能

- **逐日收支**: 由年積日決定 Kc 與耗水限值，再計算當日耗水量
- **固定灌溉深度**: 只有耗水量超過限值才灌溉，深度為 uI × 效率 − 截留量
- **管理目標**: c、d 可依淺層土、幼樹或山坡地缺水調整
- **視覺化呈現**: 提供圖表和步驟說明，便於理解和應用

## 🔬 科學基礎

### 計算原理

當日計算依序為：

```
ETo = Ux / Vx²
Ux = e^(0.0133x − 2.56) × 0.0133 × 1600
Vx = e^(0.0133x − 2.56) + 1
Ks = min(1, (Fc − D[x-1]) / (Fc × 0.67))
ETc = ETo × Kc × Ks
D = D[x-1] + ETc − Pe
```

x 是年積日（1 月 1 日為 0）。Kc 沿基礎曲線內插，再依樹齡與種植密度縮放。Fc 為質地係數乘根深。耗水限值 RAM = Fc × 當日 c 或 d。

只有 D 大於 RAM 才灌溉：

```
I = uI × 灌溉效率 − INi
```

完整節點與係數見 [計算指南](calculation-guide.md)。

## 🚀 使用方法

### 1. 系統啟動

1. 開啟 `index.html` 檔案
2. 確保所有依賴檔案位於正確位置
3. 系統將自動載入預設參數

### 2. 參數設定

#### 日期與植株
- **計算日期**: 決定年積日、Kc 與耗水限值
- **樹齡**: 決定 Kc 曲線範圍
- **種植密度**: 未滿 10 年時以「較大／較小」調整 Kc，並把毫米換算成每株公升

#### 土壤
- **質地與根深**: 決定根層田間容水量 Fc
- **c、d**: 決定當日耗水限值
- **初始耗水量**: 前一日虧缺，預設 Fc×d

#### 雨量與灌溉系統
- **當日雨量**: 先扣 3 mm 截留，再受土壤可吸納量限制
- **灌溉系統與效率**: 噴灌、微噴或滴灌
- **噴頭位置**: 決定植物截留量 INi
- **灌溉深度 uI**: 預設 10 mm

### 3. 計算執行

1. 設定所有必要參數
2. 點擊「開始計算」按鈕
3. 系統將顯示計算結果和建議

### 4. 結果解讀

#### 主要結果
- **灌溉量**: 建議灌溉深度 (mm)，並換算每株公升
- **當日耗水量**: 灌溉後的土壤水分虧缺 (mm)
- **耗水限值**: 當日 RAM (mm)；未超過時，會估算無降雨下幾天後超過

#### 詳細分析
- **計算步驟**: 顯示完整計算過程
- **水分平衡**: 土壤水分狀況分析
- **管理建議**: 基於當前條件的建議

## ⚠️ 注意事項

### 使用限制
- 本系統專為柑橘類作物設計
- 適用於亞熱帶氣候條件
- 參考蒸發散量只隨年積日變化，不使用即時氣溫或風速
- 需要當日雨量，以及接近實際的初始耗水量

### 精度考量
- 計算結果為估算值，實際應用需結合現場觀察
- 極端天氣條件下建議調整參數
- 定期校正土壤水分感測器
